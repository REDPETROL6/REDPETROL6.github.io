Privacy Policy - n8n-perso

Last updated: November 17, 2026

n8n-perso is a personal tool used only by its developer, on the developer's own Gmail account.

Data accessed

Through the Gmail API, the app reads email messages of the developer's own mailbox (sender, subject and, where enabled, message text) and creates or applies labels.

How the data is used

The data is used only to sort the developer's own inbox. It is processed on the developer's own server. Message data may be sent to Google's Gemini API solely to classify messages. It is not used for advertising, not sold, and not shared with anyone else. Use of Google user data complies with the Google API Services User Data Policy, including its Limited Use requirements.

Storage and deletion

The app keeps only the data needed to run the workflow, on the developer's own server. Access can be revoked at any time at myaccount.google.com/permissions.
